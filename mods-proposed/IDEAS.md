# ACE mod ideas (ACBuilds)

Verification: Player_Death.cs (OnDeath, Die, InflictVitaePenalty, CalculateDeathItems, GetNumItemsDropped, HandlePKDeathBroadcast, ThreadSafeTeleportOnDeath) and Player_Xp.cs (EarnXP, GrantXP, GrantLevelProportionalXp, SpendXP, RefundXP) verified via raw GitHub. Mods folder holds IHarmonyMod, ModManager, ModContainer, ModCommands, ModHelpers, ModMetadata (verified listing; BasicMod/BasicPatch API taken from local PatchClass.cs). Everything else marked UNVERIFIED must be checked in source before coding. WebSearch of forums/other mods was not done. Rules: no speed/velocity mods (client-side); no mods that add many world objects (Quest memory).

Common style: [HarmonyPatch] class : BasicPatch<Settings>, [CommandHandler(name, AccessLevel, CommandHandlerFlag.RequiresWorld, paramCount, desc, usage)], PlayerManager.GetOnlinePlayer, ActionChain(player, ...).EnqueueChain(), GameMessageSystemChat.

1. XpBoost (feas 5) - Configurable XP multiplier (per-level tiers, weekend event). Postfix/prefix on Player.EarnXP(long, XpType, ShareType) scaling amount by Settings.Multiplier. Cmds: /xpboost [x] (Admin). Settings: Multiplier, MaxLevel, XpTypes affected. Risks: double counting via GrantXP (which calls EarnXP? check); prefix arg change with ref long amount.
2. GentleDeath (feas 5) - Softer death: fewer dropped items, reduced vitae. Postfix on Player.GetNumItemsDropped(Corpse) (return __result, cap), prefix on InflictVitaePenalty(int) to scale amount. Settings: MaxItemsDropped, VitaeAmount, ProtectPlayerCorpseOnly. Risks: balance; PK paths.
3. WhereIsEveryone / PlayerFinder (feas 5) - Admin /who with location, level, landblock; /gotoplayer via player.Teleport(target.Location), /bring. Uses PlayerManager.GetAllOnline (UNVERIFIED name; existing code uses GetOnlinePlayer). Settings: none. Risks: minimal.
4. AnnounceEvents (feas 4) - Scheduled server broadcasts and timed XP/loot events (System.Threading.Timer + PlayerManager.BroadcastToAll (UNVERIFIED)). Cmds: /event start|stop name. Settings: schedule list. Risks: timer threading; wrap in ActionChain.
5. HomeStone / SetHome (feas 4) - /sethome saves player.Location to a settings JSON/DB property; /home teleports with cooldown, blocked in combat (player.LastPkAttackTimestamp / IsPKType UNVERIFIED). Settings: CooldownSeconds, AllowIndoors. Risks: teleport into invalid cell; use Teleport(Position).
6. SafeTutorZone / PkGuard (feas 3) - Disable PvP damage in configured landblocks by prefixing Player.TakeDamage / Creature damage path (UNVERIFIED exact method; inspect Player_Combat.cs). Settings: landblock list. Risks: skipping original with prefix returning false; hard to test.
7. AutoLoot / PickupRadius (feas 3) - /autoloot: on corpse open (Corpse.Open / Container.Open UNVERIFIED) move items to pack via player.TryCreateInInventoryWithNetworking. Settings: filters (pyreals, trade notes). Risks: pack full, races.
8. Buffbot Command (feas 4) - /buffme casts standard buff list via player.CreateSingleSpell / EnchantmentManager (UNVERIFIED); cooldown, free or cost. Settings: spell ids, cost. Risks: spell id correctness, balance.
9. Leaderboard (feas 4) - /top shows level/XP/kills from PlayerManager.GetAllPlayers (UNVERIFIED) plus kill tally via postfix on Player.OnDeath/Creature.Die. Settings: size. Risks: offline players load cost, cache.
10. AdminAudit (feas 5) - Log every admin command and spawn to a file. Patch CommandManager.ParseCommand (UNVERIFIED) prefix, or use own [CommandHandler]s. Settings: log path. Risks: none.
11. DeathReport (feas 5) - Postfix Player.OnDeath: broadcast fun message, log location, optional /lastdeath teleports player to death location (store Position from Location at Die). Settings: broadcast on/off. Risks: spam.
12. RestartWarn / Maintenance (feas 4) - /restartin N broadcasts countdowns then calls shutdown (ServerManager.Shutdown UNVERIFIED) and blocks logins in the window. Settings: warn intervals. Risks: shutdown API must be checked.

Ranking is by usefulness times feasibility; 1-3 and 10-11 are the best first builds.

## Round 2 (ideas 13-18), researched 2026-09-21 with WebSearch/WebFetch

Namespaces verified from raw.githubusercontent.com/ACEmulator/ACE/master/Source/ACE.Server: Player partials = ACE.Server.WorldObjects; PlayerManager = ACE.Server.Managers. Anything else is marked UNVERIFIED. No speed mods, no many-object mods, no ace_auth/ace_shard access, no passwords.

13. MilestoneRewards (feas 4) - Grants skill credits (and a chat line) at configured levels/first-time milestones, a common small-server "no reason to reroll" QoL. Hooks: Postfix on Player.CheckForLevelup (ACE.Server.WorldObjects; UNVERIFIED name, inspect Player_Xp.cs) then player.AddSkillCredits(int) (verified in Player_Skills.cs, ACE.Server.WorldObjects). Notify via GameMessageSystemChat (ACE.Server.Network.GameMessages.Messages). Cmd: /milestones (player) shows next reward. Settings: LevelToCredits map, OneTimeOnly. Risks: double-grant on relog (track in mod's own JSON keyed by character id, not the DB); balance. Source: https://github.com/aquafir/ACE.BaseMod (patch-template ecosystem, credits/XP tweaks are typical samples).

14. IdleKick (feas 4) - Warns then logs off players idle beyond N minutes to free slots and stop AFK-camping. Hooks: Postfix on Player.Player_Tick(double) or Heartbeat(double) (both verified in Player_Tick.cs, ACE.Server.WorldObjects); compare to last-input time kept in a per-player dictionary updated in Postfix on Player.OnMoveToState(MoveToState) (verified); kick via Session.LogOffPlayer(bool) (used in Player_Tick.cs; class ACE.Server.Network.Session). Cmd: /idle (Admin) list idle times. Settings: WarnMinutes, KickMinutes, ExemptAdmins. Risks: chat/casting-only players look idle (also hook chat); Tick postfix cost, so throttle to once per few seconds. Source: https://raw.githubusercontent.com/ACEmulator/ACE/master/Source/ACE.Server/WorldObjects/Player_Tick.cs (no idle logic exists, only teleport timeout).

15. TimedMute (feas 5) - Admin /mute name minutes [reason] with auto-unmute and a persisted list, wrapping stock gag. Hooks: PlayerManager.GagPlayer(Player issuer, string playerName) and UnGagPlayer(Player, string) (verified, ACE.Server.Managers); Timer/ActionChain to un-gag; Postfix Player.OnEnterWorld/PlayerEnterWorld() (verified, Player_Networking.cs) to re-apply. Cmds: /mute, /unmute, /mutes (AccessLevel.Sentinel, CommandHandlerFlag.RequiresWorld). Settings: DefaultMinutes, MaxMinutes. Risks: stock gag may already expire (GagsTick exists in Player_Tick.cs, check its semantics); relies on gag fields, do not touch DB directly. Source: https://raw.githubusercontent.com/ACEmulator/ACE/master/Source/ACE.Server/Managers/PlayerManager.cs

16. SkillRespec (feas 3) - /respec skillname lets a player un-specialize or untrain one skill and get credits back, with a cooldown and optional cost, a top request on private servers (mistaken specializations). Hooks: Player.UnspecializeSkill(Skill, int), UntrainSkill(Skill, int), ResetSkill(Skill, bool refund) (all verified, Player_Skills.cs, ACE.Server.WorldObjects; Skill enum = ACE.Entity.Enum). Prefer calling these from own [CommandHandler]; no patch needed. Settings: CooldownHours, CostPyreals (UNVERIFIED how to deduct: check Player.TryConsumeFromInventoryWithNetworking), AllowUntrain. Risks: refund exploits (spec/unspec loops: enforce cooldown); credits accounting, test on a throwaway char. Source: https://raw.githubusercontent.com/ACEmulator/ACE/master/Source/ACE.Server/WorldObjects/Player_Skills.cs

17. PkNight (feas 4) - Scheduled PK windows (e.g. Friday 20:00-22:00) for servers that are PvE otherwise: announces, flips PK status for all online players, flips back, with warnings and an /pknight now|off admin override. Hooks: PlayerManager.UpdatePKStatusForAllPlayers(string worldType, bool enabled) and BroadcastToAll(GameMessage) (both verified, ACE.Server.Managers); timer wrapped in ActionChain. Settings: Schedule list, WorldType string (UNVERIFIED accepted values: read method body), WarnMinutes. Risks: players logging in mid-window need status set (Postfix PlayerEnterWorld); pairs with PkGuard, keep tutor zones safe. Source: https://raw.githubusercontent.com/ACEmulator/ACE/master/Source/ACE.Server/Managers/PlayerManager.cs

18. LoginGreeter (feas 5) - Per-login MOTD plus "who is online / what's new / next event" whisper, with a first-login welcome pack of tips. Hooks: Postfix Player.PlayerEnterWorld() (verified, ACE.Server.WorldObjects); PlayerManager.GetOnlineCount() and GetAllOnline() (verified); GameMessageSystemChat. Cmd: /motd (player), /setmotd text (Admin). Settings: MotdLines, ShowOnlineCount, FirstLoginTip. Risks: chat sent before client ready (delay 2-3 s via ActionChain); keep it small, no world objects. Source: https://github.com/tombohar/aeshnidae-server (fetch returned 404; idea taken from the search result listing of ACE mod-host servers) and PlayerManager.cs above.
